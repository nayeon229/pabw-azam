# P9 — Koleksi Jersey Bola

Folder ini melanjutkan proyek P8 tentang koleksi jersey bola. File `js/app.js` masih memakai file dari P8, sedangkan kode untuk daftar, filter, dan validasi form ada di `js/dom.js`.

## Yang ditambahkan
- Daftar jersey ditampilkan dari data yang sudah ada.
- Tombol filter memakai satu event listener pada bagian induknya.
- Daftar dikosongkan dulu setiap kali ditampilkan ulang, termasuk saat hasil filter kosong.
- Form diperiksa per kolom dan halaman tidak dimuat ulang saat tombol dikirim.

## Cek sebelum dikumpulkan
1. Buka `profil.html` lewat Live Server.
2. Coba tombol Semua, Home Jersey, dan Away Jersey.
3. Kirim form dalam keadaan kosong, lalu isi kolom satu per satu.
4. Periksa Console untuk memastikan tidak ada error.
5. Isi tabel pengujian di worksheet berdasarkan hasil yang benar-benar terlihat, lalu ambil tiga screenshot yang diminta.

## Deklarasi AI
Saya memakai bantuan AI untuk memahami instruksi worksheet dan mengecek susunan kode. Topik koleksi jersey dan data yang dipakai berasal dari proyek saya sebelumnya. Saya tetap perlu menjalankan dan memeriksa halaman sendiri sebelum mengumpulkan.
