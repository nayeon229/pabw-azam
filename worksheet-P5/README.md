# P5 - Layout Modern: Flexbox dan Grid

## A. Kerangka Halaman

- Layout utama menggunakan Grid.
- Navbar menggunakan Flexbox.
- Isi halaman menggunakan Grid dengan dua kolom.
- Galeri menggunakan Grid.
- Isi kartu menggunakan Flexbox.

## B. Layout

- Menggunakan Grid untuk kerangka halaman.
- Menggunakan Flexbox untuk navbar.
- Menggunakan Grid untuk bagian isi halaman.
- Spacing menggunakan `gap`.

## C. Komponen dan Galeri

- Membuat galeri menggunakan Grid.
- Jumlah kolom galeri dapat menyesuaikan ukuran layar.
- Isi kartu menggunakan Flexbox.

## D. Span dan Named Areas

- Mengatur posisi beberapa bagian menggunakan Grid.
- Menggunakan `span` untuk membuat elemen melebar.
- Menggunakan named areas untuk mengatur posisi elemen.

## E. Kasus Sulit

- Mencegah teks keluar dari kartu.
- Mengatur ukuran kartu agar tetap rapi.
- Melakukan pengecekan pada ukuran layar 360px dan 1280px.

## F. Pemeriksaan

- Grid digunakan untuk layout utama.
- Flexbox digunakan untuk komponen.
- Menggunakan `gap`.
- Menggunakan `fr`, `minmax()`, dan `repeat()`.
- Galeri dapat menyesuaikan jumlah kolom.
- Tidak terjadi overflow.
